# AllenM-Samplebook

A public samplebook of automation builds, workflow patterns, and implementation notes that can be shared as portfolio examples.

## Current Samples

- `EnmessaraAI Website Lead Qualification MVP/` - website lead qualification flow with voice AI follow-up, call analysis, lead logging, and internal notifications.
- `doolittle-dentistry/` - sanitized dental appointment and call automation build notes.
- `earnhardt-auto-shop/` - sanitized automotive service and follow-up automation examples.
- `HeyGen-Avatar-Automation/` - script-to-avatar-video pipeline using Google Docs/local text input, ElevenLabs audio generation, HeyGen avatar rendering, and ffmpeg stitching.
- `agent-suites/` - complete saved agent-suite library with 154 Codex-compatible skill prompts, supporting assets, and a granular implementation plan.

## Public Safety

This repository is intended to be public. Workflow exports and documentation should use placeholders for API keys, tokens, webhook hosts, credential IDs, phone numbers, account emails, and private resource IDs.

Before adding a new workflow:

1. Confirm whether an unsanitized/private copy exists in another repo.
2. Keep or move the private version as needed.
3. Strip secrets and replace production identifiers with placeholders.
4. Add a short README or case-study note explaining what the sample demonstrates.
